About

Builds a workout as a comic strip of stick figures (or outline figures), for printing and sticking on a wall. Each panel is one exercise with one, two or three poses, plus sets, reps, time, weight and rest. Start from a preset in the library and adjust it, or pose a figure from scratch. Everything runs in this tab. There is no network call and no analytics.

Posing

how the figure works
Bones have fixed lengths, so a figure always looks like the same person. Dragging a joint turns the bone above it around its parent, and everything below keeps its own angle, so pulling an elbow moves the hand with it. When dots sit on top of each other, Next point (or the ] and [ keys) steps through them one at a time, the picked dot turns red with its name beside the button, and the arrow keys move it. Figures are flat, side or front view as you choose to draw them. Near limbs are drawn solid and far limbs lighter.

Printing to PDF

Use Print, then choose Save as PDF as the destination. The page size and orientation come from the Sheet settings, margins are set to none by the page itself, and the preview is what you get. If colours go missing, turn on background graphics in the print dialog. The PDF is vector, so it stays sharp at A3.

Saving

Save JSON writes the whole plan to a file you can load again. Export HTML writes the sheets as a single page with no script in it, which you can open in any browser, share or print to PDF. The plan is also kept in this browser automatically. Loaded files are checked and cleaned before use, so a damaged file cannot put the tool into a bad state.
